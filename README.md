# web

Static copy of my personal site (formerly lsub.org on WordPress), served by
GitHub Pages at https://fjballest.github.io/.

Plain HTML, no build step. Each page is `<slug>/index.html`, with the shared
look in `style.css`. All links are relative, so the site works at the root
or at the root of a custom domain.

To edit a page, change its `index.html`. The navigation menu is repeated in
every page's `<nav>`, so a menu change has to be made in all of them.
